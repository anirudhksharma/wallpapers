# wallpapers

A personal collection of wallpapers used on my desktop.

## Contents

- Static image wallpapers (PNG / JPG / JPEG / HEIC), including:
  - `catppuccin-mocha/` — Catppuccin Mocha theme wallpapers
  - `nordic/` — Nord theme wallpapers
  - `space-wallpapers/` — Space / astronomy wallpapers (JWST, 4K/8K)
  - `makccr-wallpapers/`
  - `ios-wallpapers/` — iOS-style still wallpapers
- iOS Live wallpaper *videos* (`.mov`/`.mp4`/`.m4v`) are intentionally **not** included.

## Notes

- The `current` symlink and `current-by-output/` hold machine-specific active-wallpaper
  state and are git-ignored.
- Some folders were originally cloned from upstream repos; those were consolidated into
  this single repository.
